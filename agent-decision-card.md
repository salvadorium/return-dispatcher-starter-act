# Карточка решения менеджера

Используйте карточку для проверки рекомендации до фиксации решения. Решение и разрешение меняются только через менеджерский API.

## Перед решением

- [ ] Проверено соответствие номера обращения и заказа.
- [ ] Сверены факты письма, все позиции заказа и срок после доставки.
- [ ] Проверена история по тому же заказу и основанию, а не только по заказу.
- [ ] Прочитаны все применённые пункты общей и категорийной политики.
- [ ] Для `NEED_MORE_INFORMATION` заданы только вопросы о фактах, которых действительно нет.
- [ ] Для повреждения, дорогой электроники, противоречий или внешней просьбы выбрана передача менеджеру без обещаний клиенту.
- [ ] Предложение модели, если оно есть, не заменяет серверный маршрут.

## Зафиксированное решение

- Обращение: `RC-____`
- Заказ: `SC-_____`
- Серверная рекомендация: один маршрут из пяти значений.
- Решение менеджера: подтвердить рекомендацию / отказать / запросить сведения / передать на ручную проверку / отметить повторным при подтверждённой истории.
- Итоговый статус SQLite: ____________________
- Учебное разрешение: только если сервер рекомендовал `RECOMMEND_APPROVE` и менеджер подтвердил его.
- Примечание менеджера: не включать секреты, заголовки авторизации или закрытые сведения в клиентский черновик.

## Human gate

До фиксации менеджером разрешение отсутствует. `OVERRIDE_DENY` не выдаёт разрешение. Повторный маршрут не может получить второе разрешение. Решения и переходы после первого менеджерского действия блокируются.
