# Runbook сдачи и демонстрации

## Быстрый запуск

Следуйте командам Windows/macOS из [README.md](./README.md). Локальный сервер слушает `127.0.0.1:5000`; приложение не запускает внешние бизнес-операции.

## Подготовленное демонстрационное состояние

SQLite в `data/runtime/returns.sqlite3` содержит 16 разобранных дел со статусами, анализом, решением менеджера и разрешениями для подтверждённых рекомендаций одобрить. При подключённом API в базе дополнительно сохраняются предложения модели; при локальном режиме используются правила сервера. Для чистого прогона выполните:

```sh
flask --app app reset-data
```

Сброс стирает решения и журнал, поэтому после него снова разберите дела и подтвердите каждое решение в интерфейсе. Не передавайте базу как источник стартовых данных; JSON в `data/` остаются неизменными.

## Сценарий показа

1. Откройте `http://127.0.0.1:5000`; проверьте очередь из 16 дел и карточку RC-6001.
2. Оставьте роль «Менеджер», откройте карточку, проверьте заказ, историю, факты, правила, маршрут и два черновика.
3. Переключитесь в «Клиент»: внутренний маршрут, менеджерская заметка и история не должны отображаться.
4. Вернитесь в «Менеджер» и проверьте итоговые обращения RC-6014, RC-6015, RC-6016: ручная проверка, обработанный повтор и подтверждённое возвратное разрешение соответственно.
5. Снимки экрана: `screenshots/01-queue-manager.png`, `02-client-view.png`, `03-case-RC-6014.png`, `04-case-RC-6015.png`, `05-case-RC-6016.png`.

## Проверка журнала и секретов

- `GET /api/audit` требует демонстрационную роль менеджера.
- Журнал фиксирует ID дела, источники, маршрут, пункты правил, переход, действие менеджера и учебное разрешение.
- Перед передачей проверьте, что `.env`, `data/runtime/`, `*.sqlite3` и журналы не входят в Git.
- Не вставляйте API-ключ в скриншоты, промпты, документацию или SQL. Отключите/уберите секрет из окружения после прогона.

## Тестирование

```sh
python -m unittest discover -s tests -v
```

Тесты используют временную SQLite и не требуют внешнего AI API. Подключение модели проверяется отдельно только при наличии безопасно заданного ключа.
