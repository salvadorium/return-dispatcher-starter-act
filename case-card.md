## Заполненный пример: RC-6014

| Поле | Результат |
|---|---|
| ID обращения / дата | RC-6014 / 10.09.2026 |
| Клиент / номер заказа | Роман Козлов / SC-84690 |
| Товар, категория, стоимость | Планетарный миксер «Микс 5», кухонная техника, 12 990 ₽ |
| Дата доставки / дней до обращения | 01.09.2026 / 9 дней |
| Причина по письму | Потёртость на внутренней стороне чаши |
| Состояние, использование, комплект | Потёртость описана; клиент не включал миксер; полнота комплекта не подтверждена |
| Найденная история и совпадение основания | RH-5896 — информация об установке насадки; другая причина, не дубликат |
| Применённые пункты политики | P-1—P-5, C-5 |
| Недостающие факты | Есть ли в комплекте все принадлежности и документы |
| Маршрут сервера | `NEED_MORE_INFORMATION` |
| Объяснение остановки / передачи | C-5 требует подтвердить полный комплект; известные факты повторно не спрашиваются |

| Учебное разрешение | Не создано |
