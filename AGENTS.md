# Правила работы с проектом

- Не изменяйте стартовые JSON-файлы и документы политики.
- Следуйте ограничениям `spec.md` и полному дизайну в `agent-spec.md`.
- Сервер — единственный источник истины для маршрутов, прав ролей, переходов состояний и разрешений. Не доверяйте маршруту или действию, присланному из браузера/модели.
- Не показывайте клиентскому контуру маршрут, менеджерское объяснение или закрытые внутренние заметки.
- Не отправляйте сообщения, не вызывайте внешние системы и не выполняйте финансовые операции.
- Не записывайте секреты, заголовки авторизации или ключи доступа в базу, ответы API или журнал.
- Все файлы и SQLite используйте с UTF-8; локальное состояние храните в игнорируемой `data/runtime/`.
- После изменения Python-кода запускайте `python -m unittest discover -s tests` из выбранного интерпретатора. Проверяйте HTML/JS синтаксис при изменении интерфейса.
- Не добавляйте новые зависимости без необходимости; зависимости приложения фиксируйте в `requirements.txt`.
