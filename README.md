# Клевер Маркет — диспетчер по возвратам

Локальное учебное приложение для разбора очереди RC-6001—RC-6016. Flask API связывает обращения с заказами, проверяет историю и политику, сохраняет рекомендации в SQLite и показывает раздельные клиентские и менеджерские материалы в одной HTML-странице.

## Запуск (Python 3.13, Windows/macOS)

Требуется Python 3.13. SQLite входит в стандартную библиотеку Python.

**Windows PowerShell**

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

**macOS**

```sh
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:5000`. Первый запуск импортирует стартовые JSON в `data/runtime/returns.sqlite3`. Локальные состояние и журнал находятся в игнорируемом `data/runtime/`.

## Подключение языковой модели

Для внешнего OpenAI-compatible Chat Completions API задайте переменные окружения перед запуском:

```text
OPENAI_API_KEY=<секрет, не сохранять в репозитории>
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
```

На Windows задайте секрет через PowerShell `$env:OPENAI_API_KEY = '...'`, на macOS — `export OPENAI_API_KEY='...'`. `.env.example` — только пример: приложение не загружает его автоматически.

AI API вызывается сервером при анализе дела. Провайдер получает текст письма, товар и категорию, предварительную серверную оценку и тексты политик. Выбирайте только одобренный провайдер и учитывайте требования к персональным данным. Секрет остаётся в переменной окружения и HTTP-заголовке запроса; не добавляйте его в файлы, SQL, ответы API, промпты или журналы. Без ключа работает локальный детерминированный анализатор правил; ответы этого режима не являются ответами языковой модели.

Модель предлагает маршрут и два текста, но серверный маршрут, состояние дела, права действия и момент выдачи учебного разрешения проверяются независимо. Модельные тексты клиенту доступны только менеджеру для редактирования/проверки. Приложение само не отправляет сообщения, не вызывает внешние бизнес-системы и не выполняет финансовые операции.

> Переключатель «Клиент / Менеджер» и заголовок `X-Role` предназначены только для демонстрации. Они не являются аутентификацией или авторизацией для реального развёртывания.

## Сброс очереди

Команда удаляет локальные решения, разрешения и аудит, затем повторно импортирует неизменённые стартовые данные. Она не редактирует JSON и документы политики.

```sh
flask --app app reset-data
```
